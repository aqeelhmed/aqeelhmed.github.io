# aqeelhmed.github.io

Personal website for Aqeel Ahmed, PhD — theoretical physicist and quantitative researcher.

**Live site:** https://aqeelhmed.github.io/

## About

A single-page site built with plain HTML and CSS (no build step, no dependencies beyond Google Fonts). It covers background, experience, projects, skills, and contact links, and includes downloadable CV and publication list PDFs.

## Structure

```
index.html               — the site
Aqeel_Ahmed_CV.pdf        — short CV
Ahmed_CV_2026.pdf         — full academic CV
ahmed_publications.pdf    — publication list
Ahmed_photo_2.jpg         — portrait photo
```

## Updating

1. Edit `index.html` directly — content, styling, and layout all live in this one file.
2. To update a document, replace the corresponding PDF in the repo root, keeping the same filename (or update the link in `index.html` if the filename changes).
3. Commit and push to the default branch — GitHub Pages redeploys automatically.

## Notes

- Supports light and dark mode automatically, based on the visitor's system preference.
- No JavaScript framework or build tools required; just open `index.html` in a browser to preview locally.
